⑤ 优化建议(按杠杆排序)

1. context-mode 按需化(省 ~2.4k tok,7%) — 它的 11 个工具 description 全部极长(ctx_execute/ctx_search/ctx_purge 单个 600+ tok),且与 pi-lens 的 sandbox/索引能力重叠。可迁移到 pi-lens 式「默认 inactive、调用时激活」模式。
2. 清理技能索引(省 ~1k+ tok,3%) — 119 个技能里含重复 caveman、以及一批低频技能(installer/creator/upgrader 系)。删除不用的技能目录是零代码动作。
3. MCP Server 裁剪(省 ~1.2k tok,3%) — kaneo(看板)与 skill-seekers 两个 stdio/http server 常驻注入约 30 个远端工具 schema,不用的会话可临时注释掉。
4. compaction 仍关闭 — settings.json 显示 "compaction":{"enabled":false},长会话无自动压缩,36.6k 底座 + 对话增量会一路膨胀。长任务建议开启或手动 /compact。
