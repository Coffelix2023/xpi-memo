# plan.md — glimpse-console-panel / hifi

> 本阶段唯一需求事实来源。每轮深挖后覆写本文件。

## 1. 目的 (Why)

把 `/xpi-memo` 的面板从**字符网格**改造成 **800×600 像素 Glimpse 窗口**原型。

TUI 版（`.pi/prototype-design/tui-console-panel`）把 78×20 字符压到极限，
结果是「折叠是硬需求」「body 只有 15 行」这类妥协。像素媒介没有这些约束：
真实字体、真实间距、真实滚动区。本轮要回答的是——**信息架构换到桌面媒介后长什么样**。

`TUI-DESIGN.md` 把两者定义为双轨（主模式 Glimpse + 降级模式 TUI），
所以 TUI 原型原封不动保留，本轮是**独立设计对象**。

- wireframe 版本：无（本版直接起稿，见 `DELTA.md`）
- **信息架构继承**：`tui-console-panel/hifi` v2 的 4 页划分与字段集合
- **配色**：`<项目根>/THEMES.md`（shadcn oklch）

## 6. 布局几何（800 × 600）

```
纵向   header 56 + body 500 + footer 44 = 600
横向   sidebar 180 + content 620 = 800
```

| 区域 | 尺寸 | 内容 |
| :--- | :--- | :--- |
| header | 800×56 | 标题 + 状态徽标（● RUNNING / ○ PAUSED）+ 主题/语言开关 |
| sidebar | 180×500 | 4 个导航项，激活项带左 3px accent 竖条 + 淡色背景 |
| content | 620×500 | 页面内容区，内边距 24px |
| footer | 800×44 | info bar（库/记录/今日/磁盘）+ Close 按钮 |

**间距**：8pt 节奏（4 / 8 / 12 / 16 / 24 / 32）。
**圆角**：卡片 `--radius`（8px），小控件 `calc(--radius - 4px)`（4px）。
**阴影**：`--shadow-sm` / `--shadow-md`，来自 THEMES.md。

## 10. 未决问题

1. **`status-panel.ts` 的硬编码 hex 与 THEMES.md 冲突**：现役 Glimpse 实现用
   `#0d1117` / `#58a6ff` / `#161b22` 等 GitHub-dark 色值，与项目 SSOT 的 oklch 体系
   不一致。本原型只用 THEMES.md；**落地时要改 `status-panel.ts`**。
2. **`status-panel.ts` 目前只实现状态页**：其余三页的 Glimpse 版尚不存在。
   本原型覆盖 4 页，落地工作量比现状大得多。
3. **窗口尺寸硬约束**：`TUI-DESIGN.md` 写「尺寸严格为 800×600」。
   若内容超出，本原型的处理是内部滚动而非扩窗。要不要允许扩窗，落地时定。
4. **`principles.md` 的「sidebar 可拖拽 resize」不适用**：窗口固定 800×600，
   没有 resize 的余地。本轮不实现，也不删该约束（它是 hifi 阶段的通用模板条款）。
5. **sparkline 数据源**：现役 `MemoryStatus` 无「近 7 日事件量」聚合字段，
   需要按 `recentEntries[].timestamp` 现算或新增聚合字段。原型用演示数据。
6. **THEMES.md 无 success / warning 语义色**：沿用 TUI 版的处理
   （成功复用 `muted`、警告复用 `accent`），若要真绿/黄需先扩展 THEMES.md。
7. **`annotate` 徽标未注入**：见 §9 最后一条。元素身份由字典与 HTML `id` 的 57 处对齐保证。

## 11. 实现中修正的三处（相对计划初稿）

| 计划初稿 | 实际实现 | 原因 |
| :--- | :--- | :--- |
| 详情 380px | **316px** | 内宽 572（620 − 48 padding）− 列表 240 − 间隔 16 = 316；初稿没扣 padding |
| 状态页卡 + 图表 + JSON 由 JS 生成 | **卡片改为静态元素** | JS 生成的 `id` 不在 HTML 源码里，字典短码 grep 不到（实测 25 个设置短码 + 4 个卡片短码全缺）。改成静态后 57/57 命中 |
| 设置页 500px 内放下 5 组 + 详情 | **列表区 380px 独立滚动 + 详情 72px 固定** | 全展开时 20 字段 + 5 组头 = 25 行 ≈ 1100px，必须滚动；详情固定才不随滚动消失 |

**实现中修掉的两个真 bug**（真实渲染才暴露，stub 测不出）：

1. **`.pane-split` / `.table-wrap` 的 `display:flex` 压过 UA 的 `[hidden]{display:none}`** ——
   空态切不动。已加全局 `[hidden] { display: none !important }`，并删掉 4 条冗余的逐元素规则。
2. **两处 CSS 注释块缺 `/*` 开头**（设置页与待审页的区块注释），导致这两段 CSS 整体失效 ——
   设置页的 `.settings-scroll { flex: 1 }` 没生效，列表把详情面板挤出窗口。已补回。

第 2 条说明：**CSS 注释残片会让整段样式静默失效**，stub 测不出，只有真实渲染能发现。
