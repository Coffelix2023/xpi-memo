# DELTA.md — hifi ↔ wireframe 差异说明

> 结构继承 wireframe，视觉自由。**每条偏离线框的决策都必须登记在此**，未登记视为偏离。

| 日期 | 线框决策 | hifi 改动 | 原因 | 批准 |
| :--- | :--- | :--- | :--- | :--- |
| 2026-09-15 | 无上游线框 | 本版直接起稿 | 同项目没有 wireframe 产出 | — |
| 2026-09-15 | 现役 `tabTitleLines` 只渲染当前 tab 名 | tab 栏列出全部 4 个 tab, 激活项用 accent 加粗 | 零文档可读性: 只看 "Settings" 一个字推不出还有另外 3 个 tab | 用户已确认(本轮闸门) |
| 2026-09-15 | 现役 `settingsItems` 平铺 10 项 | 分 5 组、共 20 项, 组头可折叠 | 用户选定「按功能域分组」+「全量纳入未暴露字段」 | 用户已确认(本轮闸门) |
| 2026-09-15 | 现役 SettingsList 单列「标签 + 值」 | 三列「标签 / 当前值 / 备注」 | 零文档可读性: `hybrid`、`on` 本身不解释后果 | 用户已确认(本轮闸门) |
| 2026-09-15 | 现役 info bar 固定两行 | 保持两行; 仅「保存失败」视图把首行换成错误行 | 不动信息层级; 错误优先于层级说明 | 用户已确认(本轮闸门) |
| 2026-09-15 | 现役无字段说明 | 说明固定在备注列, 不随光标位置变化 | 说明始终可见, 不要求用户先移动光标 | **待确认** |
| 2026-09-19 | v1 的 body 是整块 `innerHTML` 重绘 | 改静态多容器 + hash 路由，非活动页 `display:none` | annotate 注入的徽标会被重绘冲掉；SPA 契约要求容器静态存在 | 用户已确认（闸门后补充确认） |
| 2026-09-19 | 现役待审 tab 是 SelectList 两行 | 左右分栏：左 26 列候选 + 右 49 列详情 | 一屏内要看到 rationale 与证据，不打开动作菜单 | 用户已确认 |
| 2026-09-19 | 现役最近 tab 单行拼接 `动作 · 类型 · 库 · 状态 · 时间戳` | 六列对齐表格 + 状态符号 ✓○✗⚠ | 动作与状态要一眼可辨，不需要逐字读 | 用户已确认 |
| 2026-09-19 | 现役状态 tab 是 `JSON.stringify` 逐行 dump | 4 张指标卡 + 占用条 + sparkline，原始 JSON 降为次要 | 核心数字不滚动即可见 | 用户已确认 |
| 2026-09-19 | 现役无 ASCII 降级 | 新增符号层与 auto/always/never 三态开关 | 非 UTF-8 终端下 `╭╮╰╯─│` 会碎成乱码 | 用户已确认 |
| 2026-09-19 | v1 窄屏只覆盖 Settings tab | 4 个 tab 各自定义 40 列降级 | 分栏 / 卡片 / 表格在 40 列下会碎 | 用户已确认 |
| 2026-09-19 | 全文单一 20px 行距、行间无空行 | 三级间距：模块 1 / 分组 1 / 条目 0 | 段落、分组、模块挤在一起无法区分 | 用户已确认 |
| 2026-09-19 | body 高度对所有 tab 写死 15 行 | `--page-rows` 按路由自适应（7/8/19/17） | 同一写死值造出「最近页很宽」与「设置页拥挤」两种相反症状 | 用户已确认 |
| 2026-09-19 | info bar 两行 + help 行紧贴、同距同色 | 两者之间加模块间距；色阶 foreground > muted > dim | 底部三层无法区分 | 用户已确认 |
| 2026-09-19 | tab 用 `[方括号]` + accent 字色 | 激活项背景块 + accent 下划线，去掉方括号 | 字色区分太弱，看不出当前在哪个页面 | 用户已确认 |
| 2026-09-19 | 组头行详解区留空 | 组头行显示该组一句话作用与规模 | 留空在列表底部露出 3 行空洞，像布局断裂 | 用户已确认 |
| 2026-09-19 | 最近页表头只靠 dim 色区分 | 表头下加跨 6 列的 `─` 分隔线 | dim 色区分表头与数据太弱 | 用户已确认 |
