## Context

动机见 proposal.md - Why。塑造做法的现状约束：

- 该边界是纯增量、默认关闭，且本机从未配置过 endpoint，因此**关闭态就是现状**；移除的前提是默认路径逐字节不变。
- 配置对象由显式键映射构造：`readUserConfig` 只做 JSON 解析与敏感键过滤，不校验未知键，`loadConfig` 只读取自己列出的键。因此删除键不需要迁移、不需要兼容闸门，残留键自然变为惰性未知键。
- 设置短码自述为**稳定标识符而非视觉顺序**，明文规定"新码只追加、不重编号"，因此允许号段空洞。
- 精排门控所需的 `headGap` 只有精排一个消费方（`src/decision/rerank.ts` 及其测试）。
- 文档与测试耦合：`src/decision/docs.test.ts` 断言文档提到这批开关，README 双语与 GUIDE 各有开关表，代码与文档必须同批更新。

## Goals / Non-Goals

**Goals:**

- 一次移除到位：模块、配置面、代码接线、面板表面、文档、短码同时收口，删除后仓库不再有任何决策类出站点。
- 默认可见行为不变，且删除不触碰任何治理规则（`shouldAutoStore`、`autoConfirm`、evidence-upgrade 白名单、T1 kind 枚举）。
- 删除后 `pnpm typecheck`、`pnpm -w run lint`、`pnpm test` 三条门禁全绿，不留悬空引用、孤儿短码条目或断言旧文档的测试。

**Non-Goals:**

- 不新增本地替代能力（反馈权重校正、召回命中率度量等）——那属于另一个变更。
- 不迁移或改写任何已落盘数据（L0、audit、candidates、T1）。
- 不动 sleep/心跳、离线提取与准入政策。
- 不删除 `docs/references/jev/` 评估快照。

## Decisions

**D1: 删除一次到位，不做"先冻结配置面、再删模块"。**
关闭态已是现状，冻结一轮能观察到的失败面为零网络调用，没有增量信息，只多一次提交与一次文档同步。备选的两步走被否。

**D2: 配置键直接删除，不加"已废弃但仍读取"的兼容层。**
残留键本来就是惰性未知键（解析器不报错、不生效），加兼容层等于把一个已关闭的功能继续留在配置契约里。备选"保留键但强制 false"被否：那会留下"这个功能还在"的误导。

**D3: `headGap` 随精排一起删除。**
它的唯一消费方是精排门控；保留会留下一个无人读取、无人验证的字段，并在 recall 排序里继续制造"门控"的语义联想。备选"保留字段、停止消费"被否，属于无人值守代码。

**D4: 设置短码只删不重编号，保留 `P3-1-S40`–`P3-1-S46` 空洞。**
短码是身份而非序号，历史评审记录与设计字典以旧码为准；重编号会让已引用后续号段的记录指向别的元素，收益为零、破坏面为正。备选"重编号保持连续"被否。

**D5: 面板与状态表面按"整组/整块删除"，不做条件隐藏。**
设置组、doctor 计数块与 status 字段都是为该功能专设的容器；隐藏会留下永不出现的分支与永远为零的计数。备选"置灰或隐藏"被否。

**D6: 文档保留一条"已移除"说明，不静默删文。**
读者会搜"这个扩展有没有 TypeSafe 接入"；静默删除会让答案只能从 git 历史里挖，而快照仍留在仓库里，两者必须对得上。最小形式是在 `docs/references/jev/` 就地点明移除原因并指向本变更。

## Risks / Trade-offs

- [删除后无人知道为何没有决策接入] → 在 jev 快照目录留一段移除说明并指向本变更。
- [破坏性遗漏：悬空 import、孤儿短码条目、断言旧文档的测试] → 以三条门禁收口；`src/decision/docs.test.ts` 与 README/GUIDE 必须同批处理。
- [未来出现收益证据时需要重新引入，成本高于保留] → 移除是单步提交，`git revert` 可恢复；快照保留使重新评估不必重查供应商文档。反向成本（长期维护一个既无端点又无收益证据的出站点）更高，因此接受。
- [短码空洞被后来者误判为缺失或误复用] → 在短码表附近注释 `S40`–`S46` 因功能移除而留空、禁止复用。
- [残留 `TYPESAFE_*` 环境变量被误认为仍生效] → 文档明确它们不再被读取。

## Migration Plan

纯删除，无 schema、无数据、无外部状态迁移。落地顺序，每步独立可回滚：

1. 删除 `src/decision/` 整目录（含 `docs.test.ts`）。
2. 收缩 `src/config.ts`：键、类型、默认值、`DECISION_VALIDATORS`、环境变量映射。
3. 收缩消费方接线：`src/index.ts`、`src/memory-activation.ts`。
4. 移除 `src/recall-ranking.ts` 的 `headGap` 及其测试断言。
5. 收缩表面层：`console.ts`、`status.ts`、`doctor.ts`、`panel-text.ts`、`settings-groups.ts`、`glimpse/short-codes.ts` 及相关测试。
6. 更新文档：README（双语）、GUIDE、ARCHITECTURE、TROUBLESHOOTING、`docs/COMPATIBILITY.md`，并在 `docs/references/jev/` 留移除说明。
7. 三条门禁全绿后单一提交。

回滚：`git revert` 该提交即可恢复全部能力，无需回退数据或外部状态。
